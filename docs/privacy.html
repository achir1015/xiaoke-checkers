小柯機器人跳棋遊戲　隱私權政策

生效日期：2026 年 11 月 12 日

我們不收集您的資料

小柯機器人跳棋遊戲沒有帳號、沒有廣告、沒有追蹤，也沒有分析工具。開發者沒有任何伺服器會收到您的資料。

存在您裝置上的資料

  • 暱稱、遊戲設定、音量、遊戲說明的語音設定。
  • 棋譜（每一局的走法）。
  • 您自己加入的音樂。
  • 封鎖名單（您封鎖的棋友暱稱）。
  • Anthropic API 金鑰（若您自行設定）。

這些資料只存在您的裝置上。刪除 App 就會一起刪除。

連線對賽

和朋友連線對賽時，各方的裝置透過 WebRTC 點對點直接連線，傳送暱稱、走法、聊天文字與語音（語音要自己按「加入語音」才會開啟麥克風）。這些內容不會經過、也不會保存在開發者的伺服器。

為了讓各方找到彼此，App 會使用公開的 PeerJS 配對伺服器（0.peerjs.com）交換連線資訊（房號與網路位址）；也會使用 Google、Cloudflare 的 STUN 伺服器取得對外的網路位址。這些服務不會收到聊天內容與棋局。

麥克風只在您按「加入語音」之後使用。

遊戲說明的語音

遊戲說明使用裝置內建的文字轉語音朗讀解說，不會把內容傳到開發者的伺服器。

AI 軍師（Claude）

只有在您自行輸入 Anthropic API 金鑰、並在第一次使用時按「同意」之後，App 才會把「目前的棋盤局面、各方進度、本機 AI 的分析與您輸入的問題」用您的金鑰送到 Anthropic 公司的 Claude 服務，以取得解說。不會送出您的聯絡資料。Anthropic 依其隱私權政策處理這些資料。

沒有設定金鑰或不同意時，軍師只使用裝置上的 AI，不會連網。

兒童隱私

本 App 不收集任何人的個人資料，包括兒童。
